## Welcome to my GitHub Page

This site showcases some projects like a Movie Watchlist and a Clinical Timetable app. Both use Airtable as a simple backend. The timtable app is a progressive web app (PWA) and can be installed on iOS or Android. Currently it shows a list of daily events in a clinical setting in Germany but it can be adapted to display other events. It is available in two locales, English and German. It is possible to mark events as cancelled and drag and drop the events into a new order.


### Jekyll Themes

The Pages site uses the layout and styles from the Jekyll theme orderedlist. The theme layout has been customised as can be seen in the _layouts folder.
